# Lost & Found HWR

Dies ist das Repository für die Web-App "Lost & Found HWR" – eine digitale Anzeigetafel für Studierende der HWR Berlin.

## Das Ziel

Das aktuelle System zur Meldung und Suche von Fundsachen an der HWR ist kompliziert. Man muss mehrere Pförtner-Standorte (Haus A, B, E) physisch aufsuchen oder sich auf unübersichtliche WhatsApp-Gruppen verlassen.

Unsere Lösung ist eine zentrale, digitale Pinnwand, auf der **Finder** und **Suchende** einfach Posts erstellen können.
